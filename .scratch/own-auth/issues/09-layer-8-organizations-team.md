# Layer 8 · NGO registration, validation gates, super admin, Team

Status: ready-for-agent
Type: task
Blocked by: 08
Tracker card: B4

Everything NGO Hub did for organizations and admins, plus the validation a VIC super admin performs after sign-up (design doc decisions 1, 2, 4). The organization, Team and super admin routes are fixed at this layer; web issues 13 and 14 are blocked by it (decisions R25).

## Checklist

- [ ] Organization module: repository `update(id, partial)` (today only description), `findMany` / `findWithEvents` / search add `status = 'active' AND validated_at IS NOT NULL`, `findPendingValidation()`, case-insensitive uniqueness lookup on name, email, phone, taxId; facade methods. `S3_FILE_PATHS.ORGANIZATIONS = 'organizations'`. Logos are stored as S3 keys under `organizations/<id>/`; a shared helper in the organization transformer presigns a key and passes through a value starting with `http` (legacy NGO Hub URLs); every presenter that emits `logo` goes through it (decisions R27).
- [ ] `src/modules/organization/exceptions/exceptions.ts` (decisions R33): `ORG_006` Turnstile verification failed (400), `ORG_007` statute missing or not a PDF (400). Duplicate name, email, phone or taxId reuses `ORG_004` (409).
- [ ] `src/infrastructure/providers/turnstile/turnstile.service.ts`: `verify(token, ip)` against `https://challenges.cloudflare.com/turnstile/v0/siteverify`.
- [ ] `src/usecases/organization/register-organization.usecase.ts`: Turnstile (ORG_006) → uniqueness (ORG_004, 409) → statute PDF required (ORG_007) → address stays free text, no county or city (decisions R6) → one transaction: organization `pending`, `AdminUserEntity`, web identity (hash set, email unverified, `userId`); logo and statute to S3 `organizations/<orgId>`; 24 h `confirmOrganizationLink`. Per-IP throttle 5/min.
- [ ] Extend `confirm-email.usecase.ts`: identity in realm web with a pending organization → `emailVerifiedAt`, organization `active`, consume, `organizationRegistered` to the super admins (statute link included), session + cookie. A link used on an already-active NGO just logs in.
- [ ] `update-organization.usecase.ts` (all fields, optional logo and statute files, uniqueness on update), `list-pending-validation.usecase.ts`, `validate-organization.usecase.ts` (`validatedAt`, `validatedBy`; `organizationValidated` email to its admins), `suspend-organization.usecase.ts` / `unsuspend-organization.usecase.ts` (status and `suspendedAt` only; suspend also revokes the admins' sessions via `findByOrganizationId`; identity status is not changed, so admins disabled individually stay disabled and unsuspend needs no memory of earlier states; login and the web strategy refuse an admin of a suspended NGO with AUTH_004; decisions R8; reused by the command in Layer 9).
- [ ] `src/usecases/team/`: `list-team` (admins joined with identity; status from identity + live invite `expiresAt`), `add-admin` (email free in realm web or 009; `AdminUserEntity` + identity pending_password → `send-invite`), `send-invite` (same NGO or 403; pending_password only or 400; rate limit or 010; invite link 14 days with `sentBy`; returns masked email), `set-admin-status` (not yourself → 400; disable: `disabled`, `revokeAll`, replace live tokens; enable: `active` when the identity has a password hash, else `pending_password`, and no invite is sent: an enabled admin without a password gets one through Send invite (decisions R20, a design deviation); both tracked through `ActionsArchiveFacade` as `DISABLE_ADMIN` / `ENABLE_ADMIN` from Layer 1).
- [ ] Gates: `join-organization-by-access-code.usecase.ts` refuses unvalidated or suspended NGOs; `create-event.usecase.ts`, `create-activity-log-by-admin`, `create-activity-log-by-regular-user`, `approve-activity-log` throw ORG_005 for an unvalidated NGO. (The suspended-NGO check on login is in Layer 6 and the web strategy in Layer 4, decisions R8.)
- [ ] Controllers: `src/api/organization/organization-registration.controller.ts` (`POST /organizations/register`, public, `FileFieldsInterceptor([{ name: 'logo', maxCount: 1 }, { name: 'statute', maxCount: 1 }])`), `src/api/admin/organizations.controller.ts` (`admin/organizations`, `@UseGuards(WebJwtAuthGuard, SuperAdminGuard)` in that order, not `@Roles` (decisions R28): `GET pending-validation`, `PATCH :id/validate`, `PATCH :id/suspend`, `PATCH :id/unsuspend`), `src/api/organization/team.controller.ts` (`organization/team`: `GET`, `POST`, `POST :userId/invite`, `PATCH :userId/disable`, `PATCH :userId/enable`), `organization.controller.ts` `PATCH /organization` multipart with `UpdateOrganizationDto`. Register in `api.module.ts`.
- [ ] Specs: register (statute missing or not a PDF → ORG_007, Turnstile refused → ORG_006, duplicates → ORG_004 409), confirm (NGO branch), validate (403 for a plain admin), gates (refused while unvalidated, allowed after), suspend (identity status unchanged, sessions revoked; unsuspend restores login for active admins, a disabled admin stays disabled), send-invite (403 / 400 / 010), set-admin-status (self → 400; enable sends no email; events recorded), logo helper (key presigned, `http` value passed through).
